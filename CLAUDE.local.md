# Standing rules from the owner of this fork

The owner is not a developer. Follow these in every session, on top of AGENTS.md.

1. **"What would a developer ask that I don't?"** At the start of every session, and at the start of
   every new phase of a plan, ask that question yourself or through a sub-agent. Show the owner the
   questions it raises, and treat them as a risk check: answer each one, or say what is still open and
   what it could break, before the phase goes ahead.
2. **Independent review.** Before reporting any work or any problem as done or fixed, have a
   sub-agent review and validate it (the diff, the reasoning, the test results). Report what the
   reviewer found, including anything you disagreed with and why.

This file is for this fork only: leave it out of any pull request to the upstream repository.
